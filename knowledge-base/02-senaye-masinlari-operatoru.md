# Sənaye maşınları operatoru və kran operatoru kursları (AITT / ECITB)

Bu bölmədə sənaye maşınları və kran operatoru kursları var (Industrial machinery operator / Оператор промышленной техники). Bütün kurslar Azərbaycan, ingilis və rus dillərində, KVET-də və ya müştərinin ərazisində keçirilir. "FMV" — fərdi mühafizə vasitələri (PPE / СИЗ): kaska, təhlükəsizlik ayaqqabısı, jilet, əlcək, eynək; FMV tələb olunan kurslara öz FMV-nizlə gəlin.

Mobil Kran Operatoru (Mobile Crane Operator / Оператор мобильного (автомобильного) крана). Məqsəd: müxtəlif mobil kranların təhlükəsiz idarə edilməsi; neft-qaz, tikinti, kimya və gəmiqayırma üçün. Mövzular: qanunvericilik və qaydalar — LOLER, PUWER, HASAWA, BS 7121; yükqaldırma heyətinin rol və vəzifələri; kran növləri, imkanları, məhdudiyyətləri, terminologiya və meydançanın dayanıqlığı; yük həddi göstəricisi (RCI) və təhlükəsiz iş yükü (SWL); yükqaldırma qurğuları — növləri, seçimi, istifadəsi və bərkidilməsi; rabitə — radio, şifahi və əl siqnalları; kranın işə uyğun konfiqurasiyası, yükə nəzarət, yükün çəkisi və ağırlıq mərkəzinin hesablanması; gündəlik texniki baxım, sənəd və sertifikatların yoxlanılması. Qiymətləndirmə: yazılı və praktiki. Yeniləmə (refresher) və qiymətləndirmə: 1 gün. Etibarlılıq: 3 il. Qrup: 2–4 nəfər. İlkin tələb: ən azı 3 il təcrübə. Praktiki məşğələlər ECITB təlim tələblərinə uyğundur. FMV ilə gəlin.

Körpülü Kran (Overhead Crane / Мостовой кран). Məqsəd: körpülü kranlar, portal kranlar, monorelslər, stasionar tallar və konsol (jib) sistemlər kimi yuxarı yükqaldırma avadanlığı üzrə bilikləri artırmaq. Mövzular: giriş; qaydalar və standartlar; qaldırma planı, qəzalar; körpülü kran növləri; kranın vəziyyəti; markalanma; yol dayaqları (runway stops); araba əyləcləri; elektrik avadanlığı; idarəetmə pultları; cərəyan ötürücü; təriflər; limitlər; zərbə alətləri; qarmaqlar; polad tros (wire rope); bucaqlar və gərginlik; aksesuarlar; qiymətləndirmə. Müddət: 3 gün. Qiymətləndirmə: yazılı və praktiki. Etibarlılıq: 3 il. Qrup: 2–3 nəfər. İlkin tələb: təcrübəni təsdiq edən hər hansı sənəd. FMV ilə gəlin.

"HİAB" Operatoru (Lorry loader / HIAB crane operator / Оператор крана-манипулятора HIAB). Məqsəd: yük maşınına quraşdırılmış manipulyator kran operatorlarının hazırlığı; zəif hazırlıq qəzaların əsas səbəblərindəndir; səmərəliliyi artırmaq və sahəni təhlükəsiz etmək. Mövzular: giriş; tənzimləmə; stroplar və yükqaldırma qurğuları; qaldırıcı cihazlar; strop nöqtələri; çəki və ölçülər; rabitə; əsas hissələr; yük cədvəli (load chart); yoxlama; quraşdırma; yükləmə; təhlükəsiz istifadə; manipulyatorun idarə edilməsi. Müddət: 3 gün. Qiymətləndirmə: yazılı və praktiki. Etibarlılıq: 3 il. Qrup: 2–3 nəfər. İlkin tələb: təcrübəni təsdiq edən sənəd. AITT tələblərinə uyğun. FMV ilə gəlin.

Çəngəlli Yükləyici Operatoru (Forklift operator / Оператор вилочного погрузчика). Məqsəd: forkliftin təhlükəsiz və səmərəli idarə edilməsi, istifadədən əvvəl yoxlama, maşın və yükün dayanıqsızlığının səbəbləri. Mövzular: giriş; statistika; qanunvericilik — HASAWA, LOLER, PUWER; forkliftin hissələri; yük mərkəzi anlayışı; yük tutumunun hesablanması; ağırlıq mərkəzi; götürmə nöqtələri; dayanıqlıq üçbucağı; dayanıqlıq; təhlükəsiz idarəetmə; əlavə qurğular; parklama proseduru; yükləmə; yaxınlaşma və uzaqlaşma; yığma və təhlükəsiz yığma; mühərrik növləri; çəngəl uzadıcısı; nəzəri və praktiki qiymətləndirmə. Müddət: 5 gün. Etibarlılıq: 3 il. Qrup: 2–3 nəfər. İlkin tələb: iş təcrübəsini təsdiq edən sənəd. AITT tələblərinə uyğun. FMV ilə gəlin.

Anbar Tipli Yükləyici Operatoru — Reach Truck (Reach truck operator / Оператор ричтрака). Məqsəd: reach truck-ın təhlükəsiz və səmərəli idarə edilməsi, istifadədən əvvəl yoxlama, yük və maşının dayanıqsızlığının səbəbləri. Mövzular: giriş; statistika; HASAWA, LOLER, PUWER; müntəzəm yoxlamalar; işin planlaşdırılması; idarəetmə və avadanlığın yoxlanılması; yükün dəyişdirilməsi; avadanlığın söndürülməsi; təhlükəsiz sahə; tutum və yük mərkəzi; yükləmə; dayanıqlıq; təhlükəsiz idarəetmə; əlavələr; parklama; yaxınlaşma və uzaqlaşma; rəflərə yığma; batareyanın doldurulması və saxlanması; nəzəri və praktiki qiymətləndirmə. Müddət: tam kurs 5 gün, təcrübəlilər üçün 3 gün; yeniləmə (refresher) 1 gün. Etibarlılıq: 3 il. Qrup: 2–3 nəfər. İlkin tələb: təcrübəni təsdiq edən sənəd. AITT tələblərinə uyğun. FMV ilə gəlin.

Elektrikli Yükləyici (Electric stacker truck / Электроштабелер). Məqsəd: elektrikli ştabelyorun təhlükəsiz idarə edilməsi, istifadədən əvvəl yoxlama, dayanıqsızlığın səbəbləri. Mövzular: giriş; statistika; HASAWA, LOLER, PUWER; müntəzəm yoxlamalar; işin planlaşdırılması; idarəetmənin yoxlanılması; yükün dəyişdirilməsi; avadanlığın söndürülməsi; təhlükəsiz sahə; nominal yük mərkəzi; yükləmə; dayanıqlıq; təhlükəsiz idarəetmə; əlavələr; parklama; yığma və sökmə; rəflərə təhlükəsiz yığma; batareyanın doldurulması və saxlanması; nəzəri və praktiki qiymətləndirmə. Müddət: təcrübəsizlər üçün 5 gün, təcrübəlilər üçün 3 gün. Etibarlılıq: 3 il. Qrup: 2–4 nəfər. AITT tələblərinə uyğun.

Mobil Qaldırıcı İş Platforması — MEWP (Mobile elevating work platform / Мобильная подъёмная рабочая платформа, автовышка). Məqsəd: insanları alət və avadanlıqla birlikdə qaldıran platformaların (səbətli qaldırıcılar, qayçı tipli qaldırıcılar, tək nəfərlik qaldırıcılar, səbətli maşınlar) təhlükəsiz idarə edilməsi. Mövzular: giriş; operatorun seçilməsi; qanunvericilik; MEWP hissələri; istifadədən əvvəl yoxlamalar; MEWP növləri; yük cədvəli diaqramı; yanacaq doldurma təhlükəsizliyi; parklama; nəzəri və praktiki qiymətləndirmə. Müddət: 1 gün (tam kurs, təcrübəlilər və yeniləmə — hər biri 1 gün). Etibarlılıq: 3 il. Qrup: 2–4 nəfər. İlkin tələb: təcrübəni təsdiq edən sənəd və sürücülük vəsiqəsi. AITT tələblərinə uyğun. FMV ilə gəlin.

Torpaq Sıxıcı Operatoru (Soil compactor operator / Оператор грунтового катка). Məqsəd: torpaq sıxıcının təhlükəsiz idarə edilməsi — sinif təqdimatları, yazılı test, nəzarət altında praktika və bacarıq qiymətləndirməsi. Mövzular: giriş; komponentlər; işdən əvvəl yoxlama siyahısı; operatorun təhlükəsizlik məlumatlılığı; təhlükəsiz idarəetmə; maşına qalxma və düşmə; traktorun və maşının yoxlanılması; sıxıcının təhlükəli zonası; təhlükələr; maşının inspeksiya siyahısı; idarəetmənin əsasları; təhlükələrin müəyyən edilməsi; profilaktik baxım; təhlükəsiz işə salma və söndürmə; qiymətləndirmə. Müddət: 2 gün. Qiymətləndirmə: yazılı və praktiki. Etibarlılıq: 3 il. Qrup: 2–4 nəfər. İlkin tələb: təcrübəni təsdiq edən sənəd. FMV ilə gəlin.
